# TaskFlow — To-Do Web App

A responsive, interactive To-Do List application built using HTML5, CSS3, and Vanilla JavaScript as part of the Oasis Infobyte Web Development Internship (OIBSIP), Level 2.

## 🚀 Features

- **Add Tasks:** Create new tasks using the input field.
- **Pending Tasks:** View tasks that are yet to be completed.
- **Mark Complete:** Move tasks between pending and completed lists.
- **Edit Tasks:** Modify pending task descriptions inline.
- **Delete Tasks:** Permanently remove tasks.
- **Task Counters:** Display pending and completed task counts.
- **Timestamps:** Show when a task was created and completed.
- **Persistent Storage:** Save tasks using browser `localStorage`.
- **Empty States:** Friendly messages when either list is empty.
- **Responsive Design:** Works on desktop and mobile screens.
- **Input Validation:** Prevent blank tasks from being added.

## 🛠️ Technologies Used

- HTML
- CSS3
- Vanilla JavaScript
- Browser localStorage API

## ▶️ How to Run

1. Clone or download the OIBSIP repository.
2. Open the `Task3/TodoApp` folder in Visual Studio Code.
3. Open `index.html` using Live Server or a web browser.
4. Add a task and try editing, completing, and deleting it.
5. Refresh the page to verify that saved tasks persist.

## 💾 Data Storage

Tasks are stored in the browser's `localStorage`. They remain available after refreshing the page in the same browser, provided the browser's site data has not been cleared.
