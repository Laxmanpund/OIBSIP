# 🧮 Modern Calculator — OIBSIP Task

A modern, responsive, browser-based calculator built using HTML5, CSS3, and Vanilla JavaScript as part of the Oasis Infobyte Web Development Internship (Level 2).

## 🚀 Features

- Basic arithmetic operations: Addition (+), Subtraction (−), Multiplication (×), and Division (÷).
- Numeric buttons from 0 to 9.
- Decimal point support.
- Clear (`C`) button to reset the calculator.
- Backspace (`⌫`) button to delete the last entered character.
- Equals (`=`) button to calculate results.
- Operator chaining for sequential calculations.
- Division-by-zero error handling.
- Responsive layout using CSS Grid.
- Event listeners for button interactions.
- Custom dark theme with interactive button effects.
- Calculations implemented without using `eval()`.

## 🛠️ Technologies Used

- HTML
- CSS3
- Vanilla JavaScript


## ▶️ How to Run

1. Clone or download the OIBSIP repository.
2. Open the `level-2/Task1-Calculator` folder.
3. Open `index.html` in your web browser.
4. Use the calculator buttons to perform arithmetic operations.
