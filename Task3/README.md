# Task 3 – Temperature Converter

**Oasis Infobyte Internship – Web Development and Designing**

A responsive temperature conversion website built using HTML, CSS, and JavaScript.

## Features

- Convert Celsius, Fahrenheit, and Kelvin
- Instant conversion on form submission
- Swap source and target units
- Clear and reset the form
- Validation for invalid temperatures and absolute zero
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Open `index.html` in a web browser.
2. Enter a temperature.
3. Select the source and target units.
4. Click **Convert temperature** to see the result.
